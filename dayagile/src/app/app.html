Art'Agil

Visao

Art'Agil é o processo de desenvolvimento para streamline o ciclo de produção de Day'Art, deliminando as etapas e como elas devem ser prosseguidas para promover um ciclo de produção rapida, baseado em metodologias ágeis, cada interação tenta garantir entregas contínuas por meio de atividades bem definidas: levantar requisitos, organizar o backlog, planejar iteração, fazer a documentação, implementar a funcionalidade, testar e por fim, validar e avaliar o que foi feito. Alem da atividades, também a papéis separados como: desenvolvedores, comunicadores e o orientador.

Papeis

Desenvolvedor

  1. Implementar novas funcionalidades.
  2. Testa e corrige funcionalidades adicionadas.
  3. Cria a documentação de novos Casos de Uso.
  4. Atualizar a documentação de acordo com as mudanças de código ou arquitetura.

Comunicador

  1. Comunicar com o cliente.
  2. Checar com os desenvolvedores sobre o progresso e dificuldades.
  3. Criar notas das reuniões.

Orientador

  1. Ajuda a identificar problemas.
  2. Apontar onde esforços são mais necessários.
  3. Orientar sobre dificuldades.

Atividades

Levantar Requisitos

Conversar com o Cliente para entender o scopo do projeto e outras necessidades do projeto

Organizar O Backlog

Pegar todos os requisitos e por uma reunião com os Desenvolvedores e notas do cliente, decidir a ordem de prioridade de todos os CDUs levantados. Caso mais requisitos sejam levantados, uma nova reunião menor deve ser feita para reorganizar a ordem

Planejar Iteração

Qual Caso de Uso será feito e que documentação é esperada devem ser decididas antes de iniciar a Iteração para evitar conflito de demanda e para deixar claro quem pode ser procurado para mais informação sobre cada documento ou situação

Validar Implementação

Reunião com os outros membros da equipe e se possivel o Cliente para comfirmar se a Implementação esstá em um estado adequado para o projeto, além de, claro, garantir sua funcionalidade
